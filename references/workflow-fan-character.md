# 同人角色（有原作形象）

> **2026-11-19 起只做 4×。** 唯一执行流程是 `workflow-hires.md` §1.5；本页只保留“找参考图 / 写角色描述 / 按人设收体型”的部分。**1× 的嘴部特化、降采样自检、1px 描边、A/B 全部作废**；**2026-11-20 起每个角色只生一次图**——一次请求出 2–3 版，只从这批里挑一版，之后禁止任何重生成。

适用：顾客 / NPC 要照着某部作品的角色做（例如某个同人角色）。和“从零设计”的区别只有两点：除了原版立绘，还要 2–3 张原作图做形象锚点；这些网络图自带背景，会让 image model 输出不透明。

> **首图即基准**：每个角色的脸型、五官比例、唇形、发际线都不一样，第一次生成出来的那版就是这个角色。后续转换只负责保真，不负责重新设计；也不要为了“和其他角色画风统一”而重生成（详见 SKILL.md「最高原则」）。

> 特别矮小 / 幼态成年角色（如矮小体型角色）先读 `workflow-petite-character.md`；不要直接套普通角色 4× 620–660 高。

## 1 选参考图 2–3 张

- 优先官方设定 / 动画截图，正面或四分之三身、脸清楚、服装完整；不要选同人画风差异太大的图。
- 必须能看清 3–5 个识别特征：发型发色、外套、内搭、标志配饰、气质。示例（DeepSeek）= 深蓝长发 + 蓝白女仆装 + 鲸鱼鳍发饰 + 蓝色宝石胸针。
- 存到 `<MOD>/ref/<角色>_1.png` …，用 `upload_reference` 上传拿 URL；原图不要裁、不要改。

## 2 参考图排序（5–6 张）

`image_gen` 一次传 5–6 张（最多 10）：

- 1–3：原版 `femaleUpper_*_full.png`（画风 / 构图 / 色板锚点；女性角色就全用 `femaleUpper`）
- 4–5（或 4–6）：原作图（只提供人物特征）

prompt 必须把两组分开写，否则模型会把原作图的背景一起搬过来：

```text
参考图1、图2、图3是同一款太空酒馆像素游戏的角色胸像立绘，画风、构图、色板请严格沿用，它们的背景都是透明空区域。
参考图4、图5、图6只是《<作品>》<角色名>的<脸型/发型/服装/配饰>参考：<视觉特征…>；只取人物特征，绝对不要复制参考图的背景。
生成<角色名>的同人酒客形象：<年龄/气质>，<发型>；穿<服装>，<配饰>；<表情>。
头肩关系自然：头部不放大，脖子长度正常偏短，头靠近肩膀，躯干紧凑；肩宽按人设，纤细角色可以比参考图窄，不要为了接近原版强行宽肩；不要幼童脸、不要Q版、不要大头娃娃。
表情：<按角色写情绪：软糯/傲娇/冷淡/豪爽…>，用眉眼与唇角方向表达；4× 不限制表情（闭口、微笑、张嘴、大笑、露齿都可），不要写唇线粗细/深几档/禁止半张嘴。
高光只用与底色同色系的 1–2 档相邻色，至少 8px 成簇；不要跨色系亮斑、白色点或孤立高光。
胸像立绘构图，中特写镜头：严格从头顶裁到胸部下方一点，露出完整肩线与锁骨，聚焦面部神态、肩颈线条与胸口衣领配饰，不出现腰部及以下身体部位；不因动作拉远镜头；头顶留适当空间，左右居中，人物在画面中的占比与参考图相当（身高按人设）。
这一张是给 4 倍分辨率使用的像素画底稿：保持清晰的像素硬边与分块层次，刻画发丝分组、布料结构、眼睛层次与服饰细节，细节控制到 1–2px 级，拒绝模糊马赛克或涂抹渐变；无柔光、无照片感。
背景：人物以外的区域全部是纯色深青（#1A2A33）的平涂背景，单一颜色，无渐变、纹理、场景、墙面、文字、光晕或外描边；画面里只有人物和纯色背景。
```

参数：`image model`，1152×844。默认 3 张原版 + 2–3 张原作图；只选 2 张原作图时写成“参考图4–5”，并同步第一句编号。

构图句请用 `workflow-hires.md` §1.5② 的严格版替换（头含头发只占画高 38–40%、头顶留 8%、左右各留 8–10%、下缘裁到胸部下方一点，无腰腹）；本页模板只示范人物描述与表情写法。

**同一 prompt 一次请求出 2–3 版候选**：从里面挑构图 / 脸 / 服装轮廓最合适的一版直接做 4×。**这是本角色唯一一次生图**——不得再开第二批、不得补第二张 4× 首图；首批超宽/头大也只能在批次内换版或改裁切。**表情不设限**：闭口、微笑、张嘴、大笑、露齿都按角色写，不写唇线粗细、深几档、禁止半张嘴；情绪交给眉眼与唇角方向。高光句保留“同色系、8px 成簇”（4× 尺度）。

**不做降采样自检**（那套只服务已停用的 1×）。4× 转换后被量化掉的细节，优先补色板槽或换首图批次里的另一版，不二次生图。

背景用纯深青平涂，是为了让 matting tool 抠图更干净：白裙、粉发不会和底色混，残留边是深色，2px 描边能盖住。实测比“要求透明底”稳定。

实例（DeepSeek 示例）：蓝白配色、深蓝长发、鲸鱼尾元素；青年女性，体态纤细、肩线自然；表情写“平静、略带好奇”，4× 不限制张嘴或露齿。

高挑型按 1× 133×166 → 4× 目标 532×664 收（历史记录，供换算参考）；肩线自然、不强行宽肩；不要为了凑宽度去拉肩，也不要做成大头/窄肩纸片人。

小个子 / 幼态角色：额外写“圆脸、脸颊有肉、下巴短而圆、五官略偏下；眼睛半睁、虹膜色可见、淡腮红”，否则容易生成长脸 / 闭眼 / 苦相的成年脸；体型按 4.5–5 头身，不要 Q 版。表情按角色写，4× 不限制嘴部。

## 3 背景与抠图：不要死磕透明底

实测：参考图里只要有一张带背景，image model 连续 3 次都会画出底色 / 渐变 / 星点，即使 prompt 写死“四角透明”也没用。

1. 生成后先验四角 alpha；如果是按透明底写的 prompt，不透明时先挑构图 / 人物最好的一版；如果用的是纯深青底，四角不透明是正常的，直接进入 `workflow-hires.md` §1.5③（选首图），再走抠图。
2. 透明底写法**不重试**（本角色只有一次生图）；仍不透明就直接按深青底 + matting tool general 抠图处理，或在首批内换一版。
3. 用 matting tool 通用抠图（`general` 适合二次元 / 动漫、非纯色背景）：

```powershell
image CLI image remove-image-background `
  --image-url "<MOD>\tools\out\patron\raw_<角色>.png" `
  --scene general --output-format png
```

> `--image-url` 传的是**本地绝对路径**（cli 直接读本地文件）；上游 `image_gen` 用的参考图才走 `upload_reference` 换 URL。

4. 下载返回的 `image_url` 到 `raw_<角色>_matte.png`，再验：四角 `(0,0,0,0)`、bbox 不是整张画布。
5. 不要用颜色键 / 魔棒：深色头发、黑内搭、皮草会被一起挖掉；matting tool 结果允许有一圈半透明边，转换脚本的 `--alpha-th 110` 会二值化。
6. **不要用 `--scene human`**：实测对二次元角色会返回全透明；动漫 / 二次元一律用 `general`。
7. matting tool 产物是 24 小时临时链接，只作为中间稿；不要直接把链接交付给用户。
8. 更稳的生成方式：直接在 prompt 里指定纯色深青 `#1A2A33` 平涂背景，再走 matting tool general 抠图。白裙、浅色发、黑内搭都不会和底色混，残留边是深色，2px 描边能盖住；示例图用这个方法一次干净。
9. 深青底 + 头发缝隙可能留少量深青 / 灰斑：6× 下像头发阴影、没有白边可接受；明显灰块 / 空洞再局部清理，不要全局色键。

## 4 色调与色板

按服装主色新建 **28–30 色**（4× 专用；1× 的 20–24 色已停用）。色板按“发色 / 外套 / 内搭 / 配饰”四组主色分别建 **3–7 档同色相阶梯**，再补眼白、虹膜、腮红与描边；示例见 `references/palettes/female_deepseek_4x.json`。

- 每个主色只取同色系亮 1–2 档做高光，不要跨色系。
- 头发、内搭、配饰各占 3–5 档，不要把一个深色只给一档。
- 眼白与虹膜单独留槽，否则眼睛会糊成一团。
- 其他配色按 `workflow-hires.md` §4 的 6 类配额建。

## 5 按人设定体型：不要硬拉宽/拉高

游戏原版 140×162 是画风/比例锚点，不是每个角色必须达到的尺寸。角色高矮胖瘦不同——**4× 体型表唯一一份在 `workflow-hires.md` §8**，本页不再复制。这里只记人设判定：纤细型（高 580–640 / 肩线宽 400–480），特别矮小型（500–580 / 340–420），高挑型（648–680 / 480–580）；宽度一律指肩线宽，宽发不含外侧发丝。

纤细型示例（历史 1× 118×160 → 4× 472×640）：窄肩、短颈、紧凑躯干；不要为了接近原版 140 宽去拉肩。
特别矮小型示例（1× 103×134 → 4× 412×536）：头略大、肩窄、躯干短；不要套普通角色 162 高/140 宽，也不要把身体拉宽。

1. 先按 `--squeeze 1.0` 转一版，量 `figure` 高度与 `body_width`（肩线宽）；落在对应体型区间就收（宽发角色宽度看 body_width，总 bbox 另按不碰边 + ≤1.15×高）。
2. 不要为了凑某个数字硬调 `squeeze`；它只改整体宽窄，改不了体型、肩宽和头肩比例。
3. 觉得“拉伸”先查脖子/躯干长度：prompt 写“脖子偏短、头靠近肩膀、躯干紧凑”，必要时把 `--height` 降到目标区间；特别矮小按 4× 500–580；不要先加宽肩。
4. `--squeeze` 固定 `1.0`，不微调；宽度不合就在批次内换版或按宽肩档收。
5. 验收看 6× 预览：肩线、脖子、躯干自然，不显长颈/纸片人，也不显宽肩壮硕。
6. **宽发女角色（长卷发 / 双马尾 / 披肩大波浪）**：宽度按“肩线宽”口径——肩线外飘散发丝不计入体型表（见 `workflow-hires.md` §1.5⑤）；但仍要满足：发丝不碰画布左右边缘（每侧 ≥8%）、总 bbox 宽 ≤1.15×人物高、不 squeeze。

```powershell
python scripts/convert_character.py --src raw_character_matte.png --out femaleUpperExample4x_o1.png `
  --key femaleUpperExample --palette references/palettes/<角色>_4x.json `
  --squeeze 1.0 --height <按 aspect 反推> --canvas 1152x844 --resample LANCZOS --outline-mode thin --despeckle 7
python scripts/add_outline_rings.py femaleUpperExample4x_o1.png femaleUpperExample4x.png 1
```

- 色板先用第 4 节的方法扩到 28–30 色，存成 `<角色>_4x.json` 再跑；不要沿用 24 色的 `female_kurumi.json`。

- `--height` 按 `workflow-hires.md` §8 的体型档与 aspect 反推：`min(目标高, 宽上限 / aspect) − 1`；抽完看 JSON 的 `figure`。
- 目标高直接取 `workflow-hires.md` §8 对应档的高度区间，本页不再抄数值。
- 只做 4×；不要再转 1×，也不做 A/B。

若抠图边缘有白边/灰边，加 `--edge-erode 1`，并把 4× 的 `--height` 相应上调（erode 1 各收 1px，最多补 2；以 JSON 的 `figure` 为准）。

**4× 是唯一交付**：体型档见 `workflow-hires.md` §8，画布 1152×844；prompt 保留像素画约束句，追加“高清像素画：更多细小色阶、细节 1–2px”，不写任何唇部/表情约束。落位用 `convert_character.py --canvas 1152x844 --palette <角色>_4x.json --outline-mode thin` + `add_outline_rings.py 1`。完整规则见 `workflow-hires.md` §1.5。首图只生一次（2–3 版挑一版），不要为 4× 再单独生成一轮。

## 6 验收（4×）

- `alpha_values == [0,255]`
- `body_width`（肩线宽）落在 `workflow-hires.md` §8 对应档的宽度区间（格式＝高 / 宽：先按 `figure` 高度落档，再按肩线宽落区间）
- 宽发女角色：肩线外发丝不计入宽度，但总 bbox 宽 ≤1.15×人物高，且发丝不碰左右边缘（每侧 ≥8%）
- 肩线、脖子、躯干自然：不显长颈/纵向拉伸，也不显宽肩壮硕；头/体宽比按人设，不强制 0.60
- `center_x ≈ 576`（574–578）、`bottom_gap 0`
- `distinct_colors 28–30`
- 描边：`--outline-mode thin` + `add_outline_rings.py 1`，最终 **2px `#292234`**；6× 预览不能有一圈白边或灰边
- 表情：**不限**；闭口/微笑/张嘴/大笑/露齿都可通过，只要能读出角色情绪；不要因“半张嘴/露齿”返工
- 高光：与底色同色系亮 1–2 档，至少 8px 成簇；跨色系亮斑、白色点、孤立单像素返工
- 眼睛颜色：棕色虹膜不要被绿色 / 灰色槽位吃掉（见 `workflow-hires.md` 的眼睛检查）
- 四联对照：原版女性（1× 放大 4 倍）/ 上一个普通或高挑角色 / 上一个纤细角色 / 本角色，**底部对齐并带高度标签**（如 VANILLA 648 / MISATO 664 / KURUMI 640 / SAKE 536），确认体型差异合理、色阶不突兀
- 头占比：和现有 4× 比，不按 bbox 卡 38–40%（现有画布口径 36–45%、人物 bbox 46–58%）。不达标才回首批换一版，**不要新开一轮生图**

## 7 命名与落位

- key = `femaleUpper<Name>4x`（含 `female`，性别称呼正确；不要用纯编号）
- 放 `Textures/Items/<key>.png`（即 `femaleUpper<Name>4x.png`），同步 `dist/<MOD>/Textures/Items/`
