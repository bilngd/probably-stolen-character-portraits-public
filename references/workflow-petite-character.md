# 特别矮小 / 幼态成年角色

适用：年龄是成年人，但设定明显比普通成年人矮小、常被误认为小孩。例：某作品的小个子角色（24 岁，官方描述“常被误认为小学生”）。这类角色**不能套常规成年女性 4× 620–660 高**，更不能为凑宽度去拉肩。

> **2026-11-19 起只做 4×。** 本页数值全部按 4× 使用；1× 的数值只作 ×4 换算。旧的 A/B、唇部特化、1px 描边都已停用。

## 1 先定身高：官方数值 → 图像比例 → 游戏像素

- 官方常不给厘米身高（矮小角色只写“小学生と間違われるほど小柄”）。不要自己编一个 cm 数写进设定；以官方描述 + 参考图比例为准。
- 角色表 / 全身图往往不是同一比例尺，不能只看画布高度；看头身比、腿长、肩宽、头肩关系。矮小角色约 4.5–5 头身，头略大、腿短、肩窄。
- 游戏里 4× 648 高 / 560 宽只是普通成年人的画风锚点，不是硬指标。把 648 当 100%：
  - “矮一截” ≈ 15–20% 矮 → 4× 520–552 高；
  - “特别矮小 / 像小学生” 取 **4× 500–580 高、340–420 宽**；
  - 矮小角色实测取 **4× 536 高、412 宽**（约为原版 648/560 的 83%/74%），和原版并排明显小一圈，但仍保留成年人的脸。
- 先定目标 H/W（4×），再反推 `--height`；不要用 `--squeeze` 拉宽。头略大、短颈、窄肩、短躯干；不要 Q 版 / 大头娃娃。

## 2 prompt：成年脸 + 幼态比例

基础同人 prompt 之外加：

```text
二十四岁成年女性，但身材特别矮小、瘦，常被误认为小学生；头略大、脸型圆润、脸颊有肉、下巴短而圆、五官略偏下；肩窄、身体短小、四肢细，头身比约 4.5–5 头身；脸保持成年人的慵懒感，不要长脸、尖下巴、苦相；眼睛半睁、棕色虹膜可见、上眼睑略压、淡淡微笑、脸颊淡腮红；不要 Q 版、不要大头娃娃、不要幼童化、不要性感化。
```

- 只写“矮小 / 像小学生”不够；模型容易给长脸、尖下巴、闭眼、苦相。必须写圆脸、短下巴、五官偏下、半睁眼可见虹膜、淡笑、腮红。
- 小个子脸更小，但 4× 分辨率仍足够：**表情不设限**（小微笑/平嘴/张嘴/大笑都行），不要写“唇线至少 8 像素粗、深 2–3 档”，也不做降采样自检。
- 高光只用与底色同色系的 1–2 档相邻色，至少 8px 成簇（4× 尺度）；不要跨色系亮斑、白色点或孤立高光。
- **一次请求出 2–3 版，挑一版直接做 4×**；这是该角色唯一一次生图，不得重开第二批、不得补 4× 首图。
- “头略大”是相对身体，不是头占满画面；保留 4.5–5 头身。
- 胸像裁到胸部下方一点（见 SKILL「构图与景别」），不出现腰腹；绿短裙等下半身特征可能不在画面内，靠发型 / 猫耳 / 连帽衫 / 困眼保留识别度。

## 3 脸不对时：先换首图候选（旧“只改脸”已停用）

新口径下不要为改脸再生成一轮：

1. 首图一次出 2–3 版，直接挑**脸最合适的那一版**；身体/构图稍差可以靠 `--height` 和裁切解决，脸不对不要硬转。
2. 如果整批脸都长/闭眼/苦相，说明这一轮首图没定下来：**只能在批次内换一版**；整批都不合就把 2–3 版并排交用户定（用哪一版 / 换角色），**不得再出第二批**。
3. 旧流程“保持身体、只改脸”只作历史记录（早期版本曾用），新角色不要照做。

> 历史做法（仅追溯）：用 `image_gen` 以当前身体图 + 原作脸 + 原版立绘三张参考，prompt 写死“只修改脸部，保持构图/体型/发型/服装不变”。这条已冻结，正常流程不要执行。

## 4 抠图与残留

- 动漫 / 二次元用 `remove-image-background --scene general`；实测 `human` 对二次元角色返回全透明，不能用。
- 深青平涂底 + 头发缝隙容易留少量深青 / 灰斑；先看 6×：
  - 像头发阴影、没有白边 → 可接受；
  - 明显灰块 / 空洞 → 只对背景色做局部清理，不要全局色键（会挖掉深色头发 / 衣服）。
- 抠完验四角 alpha=0、bbox 不是整张画布；转换脚本的 alpha 阈值会二值化半透明边。

## 5 色板：棕色眼睛 / 腮红别被吃掉

- 以 `<角色>.json` 的配色为底扩到 **28–30 色**，另存 `<角色>_4x.json`：约 7 档红棕发、7 档米色连帽衫、3 档墨绿（短裙可能不入镜）、6 档肤、3 档棕眼/虹膜、1 档腮红、1 档描边/深色。
- 眼睛发绿 / 发灰：检查转换后的眼睛像素；如果绿色槽位抢走了棕色虹膜，把未使用的绿色槽换成棕色虹膜 `(132,80,52)`。矮小角色实测替换后眼睛恢复棕色。
- 腮红：加一个 `(214,138,128)` 左右的腮红色；否则腮红会被并到肤色，脸上看不出。
- 色板总数保持 **28–30**；先保证眼睛 / 肤色 / 主衣色，再补发饰 / 裙色。

## 6 转换与验收

以下为矮小角色实测命令，文件名按实际替换（目标是 4×；先按第 5 节建好 `<角色>_4x.json`）：

```powershell
python scripts/convert_character.py --src raw_character_v3_matte.png --out femaleUpperExample4x_o1.png `
  --key femaleUpperExample --palette references/palettes/<角色>_4x.json `
  --squeeze 1.0 --height 535 --canvas 1152x844 --resample LANCZOS --outline-mode thin --despeckle 7
python scripts/add_outline_rings.py femaleUpperExample4x_o1.png femaleUpperExample4x.png 1
```

- 实测 1× `--height 133` → `figure 103×134`；4× 按 ×4 换算，目标 **412×536**，`--height` 约 535，转完以 JSON 的 `figure` 为准，必要时 ±1 再转。
- 表情：**不限**（小微笑/平嘴/张嘴/大笑都行）；不要因“半张嘴/露齿”返工，4× 不做嘴部像素级修补。
- 高光：与底色同色系亮 1–2 档，至少 8px 成簇；跨色系亮斑/孤立点返工。
- 目标：特别矮小 **4× 高 500–580 / 宽 340–420**（宽度指肩线宽）；`center_x ≈ 576`、`bottom_gap 0`、`distinct_colors 28–30`。
- 轮廓：2px `#292234`（thin + 补 1 圈）；不能有一圈白边/灰边。
- 看 6× 预览；再**做带高度标签的四联对照**（原版 648 / 普通角色 640–664 / 矮小角色 536，底部对齐），确认“矮一截”不是靠拉宽 / 拉长。
- key 用 `femaleUpperExample4x`（含 `female`）；放 `Textures/Items/` + dist；代码侧仍需注入 `SpriteDict`，`GetPool` 不自动收自定义 key。
